# Cyber Range Coach: правила для Claude

Проект ведут две машины: Mac (разработка, тесты, сборка установщика через CI) и
Windows-ноутбук (установленная академия, Docker-мишени, WSL Ubuntu, живые проверки).
Общий канал между ними это этот репозиторий. Репозиторий публичный: паролей,
ключей, токенов и личных данных сюда не класть.

## В начале каждой сессии

1. `git pull`.
2. Прочитать `goal.md` (что сделано, что осталось, раздел NEXT).
3. На Windows прочитать `docs/noutbuk/ZADANIE.md`: текущее задание для ноутбука.
4. На Mac прочитать новые файлы в `docs/noutbuk/otchety/`: отчёты с ноутбука.

## Кто что делает

- **Mac**: код, тесты (`scripts/quality.sh`), коммиты, новый установщик.
- **Windows**: мастер WSL, уроки, проверка на живом стенде. Код академии на
  Windows не править, найденную ошибку описать в отчёте.

## В конце каждой сессии

- Windows: отчёт в `docs/noutbuk/otchety/<ГГГГММДД-ЧЧММ>.md`, затем
  `git add` этого файла по имени, `git commit`, `git push`.
- Mac: обновить `goal.md` и при новом задании `docs/noutbuk/ZADANIE.md`, коммит, push.
- Файлы добавлять только по имени, не `git add -A`.

## Память проекта (Obsidian)

Память Mac и Windows разделены. Общие только карточка этого проекта и его статьи.
На Windows они лежат в мосте памяти `%USERPROFILE%\Documents\vault-bridge-mac`:
разреженный клон приватного репозитория вольта, в котором скачаны только файлы
этого проекта (список в `git sparse-checkout list`). Остальные проекты Mac на Windows
не попадают, список файлов моста не расширять без владельца.
- Windows, начало сессии: `git pull` в мосте, прочитать `memory/project_cyber-range-coach.md`.
- «запомни» на Windows: дописать в эту карточку раздел `## Update <дата> [windows]`
  (что сделано, что решено, что дальше, уроки; старое не удалять), в мосте `git add`
  карточки по имени, `git commit`, `git push`.
- «запомни» на Mac: `/zapomni`, затем коммит и push только файлов этого проекта в вольте.
- Mac перед работой делает `git pull` в вольте, чтобы увидеть записи с Windows.

## Общение с владельцем

По-русски, коротко и простыми словами, одно действие за раз, путь по кнопкам на экране.
Пароли владелец вводит сам: не вводить их за него, не спрашивать в чате, не записывать.
