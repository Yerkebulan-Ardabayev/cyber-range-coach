После `Shutting down` нет ни `Waiting for connections to close`, ни `Finished server process`: за 19 с uvicorn не завершился.
В этот момент в браузере Claude была открыта страница академии, а раньше в этой сессии открывалась лаба с терминалом (WebSocket `/api/v2/terminal/…`) и опрос `GET /api/v2/lab-runs/…` каждые 3 с.
Вероятная причина: uvicorn при штатной остановке ждёт закрытия открытых соединений (keep-alive HTTP/WebSocket) без ограничения по времени.
Предложение: `timeout_graceful_shutdown` (например, 5 с) в `uvicorn.Config` и/или закрывать WebSocket-терминалы при запросе остановки.
Тест в CI, скорее всего, шёл без открытого браузера, поэтому этого не поймал. Воспроизвести: открыть лабу с терминалом, затем `CyberRangeCoach.exe stop`.
