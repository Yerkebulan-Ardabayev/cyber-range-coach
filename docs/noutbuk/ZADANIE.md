Причина 422 (коммит `1a2aeef`): в Windows нет базы часовых поясов IANA, а сайт передаёт часовой пояс браузера (`Asia/Almaty`). Без пакета `tzdata` академия отклоняла такие запросы, то есть не сохранялись черновики и, вероятно, ответы практики команд. Пакет `tzdata` добавлен в сборку. Источник: https://docs.python.org/3/library/zoneinfo.html#data-sources
</context>
