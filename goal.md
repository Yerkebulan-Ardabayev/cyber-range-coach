- Помощь на ступени 2 = открыть скрытую команду (`POST /lab-runs/{id}/reveal-command`). Действует сутки от момента подсмотра (`help_opened_at`) в любой сессии, а в самой попытке с подсмотром всегда: пересдать только что увиденную команду чисто нельзя, чистая попытка на следующий день.

- На ступени 3 кнопки показа команды нет, API отвечает 409 `no_help_on_transfer` (решение владельца 24.09).
- Навыки без лестницы сохраняют прежнее правило (+1 ступень за зачёт, перенос по второй цели).
- 11 нелинуксовых навыков: теория и практики на темы сети и HTTP упираются в фильтр безопасности; ждёт ответа на жалобу или текста владельца.
